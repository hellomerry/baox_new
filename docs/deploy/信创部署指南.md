## 二、环境准备

### 2.1 操作系统依赖

#### 麒麟 V10（ARM64 示例）

```bash
# 系统包
sudo dnf install -y python3 python3-pip python3-devel \
                    libnsl libffi-devel openssl-devel \
                    glib2 gtk3 webkit2gtk4.1 \
                    fontconfig wqy-microhei-fonts wqy-zenhei-fonts

# Python 3.11 编译安装（系统默认 3.8 偏旧）
sudo dnf install -y gcc make
curl -O https://www.python.org/ftp/python/3.11.9/Python-3.11.9.tar.xz
tar xf Python-3.11.9.tar.xz && cd Python-3.11.9
./configure --prefix=/usr/local --enable-optimizations
make -j$(nproc) && sudo make install
sudo ln -sf /usr/local/bin/python3.11 /usr/bin/python3
```

#### 统信 UOS（x86_64）

```bash
sudo apt install -y python3.11 python3.11-venv python3-pip \
                    libwebkit2gtk-4.1-0 libgtk-3-0 \
                    fonts-noto-cjk fonts-wqy-microhei
```

#### Windows

- 安装 Python 3.11（注意勾选"Add to PATH"）
- 安装 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)

### 2.2 Python 依赖

```bash
# 使用国内源（信创/无外网环境）
pip3 install -r requirements.txt \
```

## 三、生成 TLS 证书

生产环境**强烈建议**使用内部 CA 签发的证书：

```bash
# 1. 自签（仅测试 / 内网）
python3 generate_ssl.py
# 产物：dist/certs/server.crt, server.key（3650 天）

# 2. 替换为内部 CA 签发的证书（生产）
# 拷贝 <your-ca>.crt → dist/certs/server.crt
# 拷贝 <your-ca>.key → dist/certs/server.key
```

> **注意**：所有客户端机器需信任该 CA 根证书，否则 PyWebView 会因 HTTPS 证书错误拒绝加载。

## 四、PyInstaller 打包

```bash
pip3 install pyinstaller -i https://pypi.tuna.tsinghua.edu.cn/simple/

# 三客户端打包
python3 build.py

# 产物在 dist/ 下：
#   dist/finance/finance        (~50MB, 麒麟 ARM64 ~60MB)
#   dist/auditor/auditor
#   dist/reimburser/reimburser
#   dist/center/center_node     (汇总节点，独立服务)
```

### 4.1 ARM64 vs x86_64 打包

**必须在目标架构机器上打包**。麒麟 ARM64 上打的包不能在 x86 机器上运行。

```bash
# ARM64 机器
python3 build.py --arch arm64
# 产物：dist/finance/finance-1.0-arm64.tar.gz
```

### 6.1 启动财务版

```bash

```

## 七、中心节点部署

`center_node.py` 是独立服务，监听 `0.0.0.0:5443`，支持 TLS。

### 7.1 部署位置

- 一般部署在**上级汇总单位**（如省局 → 总局）
- 需要**双网卡**或**网闸**摆渡

### 7.2 启动

```bash
# 前台
python3 center_node.py

# 后台（systemd）
sudo tee /etc/systemd/system/reimbursement-center.service <<EOF
[Unit]
Description=Reimbursement Center Node
After=network.target

[Service]
Type=simple
User=reimb
WorkingDirectory=/opt/reimbursement/center
ExecStart=/usr/bin/python3 center_node.py
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl daemon-reload
sudo systemctl enable --now reimbursement-center
```

### 7.3 防火墙放行

```bash
# 麒麟 V10
sudo firewall-cmd --permanent --add-port=5443/tcp
sudo firewall-cmd --reload

# UOS
sudo ufw allow 5443/tcp

# Windows
New-NetFirewallRule -DisplayName "Reimbursement Center" -Direction Inbound -Protocol TCP -LocalPort 5443 -Action Allow
```

## 八、数据备份与恢复

### 8.1 自动备份

启动器每次启动会滚动备份到 `backup/`，**保留最近 5 份**：

```
backup/
├── 2026-08-23_120000_reimbursement.db
├── 2026-08-24_080000_reimbursement.db
└── ...
```

### 8.2 手动备份

```bash
# 复制数据库即可
cp ~/.config/reimbursement-app/reimbursement.db backup/manual-$(date +%F).db

# 加密备份
gpg -c backup/manual-2026-08-24.db
# 产物：backup/manual-2026-08-24.db.gpg
```

### 8.3 恢复

```bash
# 停止客户端
pkill -f finance

# 恢复
cp backup/2026-08-23_120000_reimbursement.db ~/.config/reimbursement-app/reimbursement.db

# 重启
/opt/reimbursement/finance/finance
```

## 九、常见问题

### 9.1 PyWebView 启动后白屏

- **麒麟 ARM64**：安装 `webkit2gtk4.1`
  ```bash
  sudo dnf install webkit2gtk4.1
  ```
- **UOS**：安装 `libwebkit2gtk-4.1-0`

### 9.2 启动报"模块找不到"

```bash
# PyInstaller 打包时漏了 hiddenimport
# 在 build.py 的 hiddenimports 列表里加上
# 然后重新打包
```

### 9.3 HTTPS 证书错误

- 确认所有客户端机器信任自签 CA
- 或在 `config.py` 关闭 TLS（**不推荐生产**）

### 9.4 中文乱码

```bash
# 安装中文字体
sudo dnf install wqy-microhei-fonts wqy-zenhei-fonts
# 或
sudo apt install fonts-wqy-microhei fonts-noto-cjk
fc-cache -fv
```

### 9.5 数据库锁等待

SQLite 在高并发写时会锁。`config.py` 调整：

```python
SQLALCHEMY_ENGINE_OPTIONS = {
    'connect_args': {'timeout': 30, 'check_same_thread': False}
}
```

## 十、升级流程

1. 备份当前数据库
2. 停止所有客户端
3. 替换 `dist/<client>/` 目录
4. 启动新版本（自动迁移 schema，见 `models/`）
5. 验证登录、数据完整性

> ⚠️ **不要跨大版本直接升级**：v1.x → v2.x 前请先跑迁移脚本（`tools/migrate_v1_to_v2.py`，待补）。
